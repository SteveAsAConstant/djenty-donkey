# 压缩器：UREI 1176LN Rev D（元件级）

v0.6 起，插件的压缩器是 UREI 1176LN Rev D（"blackface"，S/N 1239–2331）的元件级模型，取代原来 JUCE 的通用压缩器（`juce::dsp::Compressor`，不对应任何真实设备）。

- 电路转录：[1176_schematic_notes.md](1176_schematic_notes.md)
- LTspice 参考：[spice/1176ln_revd.inc](../spice/1176ln_revd.inc)；`spice/1176_*.cir` 按原厂测试程序搭的测试台（静态曲线、Q 偏置、LN 微调、启动、释放、输出级偏置）
- C++：[Source/dsp/Urei1176.h](../Source/dsp/Urei1176.h)（电路）、[Source/dsp/SemiNetwork.h](../Source/dsp/SemiNetwork.h)（半导体 DK 求解）、[Source/dsp/Comp1176.h](../Source/dsp/Comp1176.h)（插件里的过采样和旋钮）
- 测试：`comp1176_test`（`spice` / `rates` / `release` / `null` / `metal` / `cpu` / `worst` / `stress` / `hf`）；`comp1176_nam <采样.nam> fit`：和真机 NAM 采样对比

## 模型

整台机器 25 个非线性端口：Q1 场效应管，Q2–Q10、Q14 十个双极晶体管，CR1–CR3 三个二极管，T1、T2 两个变压器（T2 带两个反馈绕组）。器件方程和 LTspice 相同：

| 器件 | 方程 | 参数 |
|---|---|---|
| 2N3391A（Q2–Q4、Q14） | Gummel-Poon，只用 Is / Bf / Br / Vaf | 6.734 fA, 400, 0.74, 74 V |
| 2N3707（Q5、Q7–Q10） | 同上 | 20 fA, 350（图注：挑选 hFE ≥ 250）, 1, 100 V |
| 2N3053（Q6） | 同上 | 50 fA, 120, 3, 100 V |
| Q1（UREI 13-0027） | Shichman-Hodges 写成对称形式，夹断边缘平滑成亚阈值导电：Id = β (f(Vgs−Vto) − f(Vgd−Vto)) (1 + λ\|Vds\|)，f(x) = (2nVt·ln(1 + e^(x/2nVt)))² | 2N5457 数据：β 1.125 mA/V², Vto −1.372 V, λ 2.3 m；n = 1.3；栅结二极管 Is 181 fA |
| CR2、CR3（FD333） | Is (e^(V/NVt) − 1) | 77 pA, N 1.7（1 mA 时 0.72 V，Fairchild 数据） |
| CR1（1N914） | 同上 | 2.52 nA, 1.752 |
| 结电容 | 固定电容（Cbc 3.6 / 4 / 15 pF，Cgd 6 pF，Cgs 7 pF） | |

场效应管为什么要亚阈值：出厂校准（"Q" 偏置）让 G.R. 关时输出刚好掉 1 dB，这时沟道电导只有约 9 µS——远在夹断以下。纯平方律模型在这里电导 ∝ (Vgs − Vto)，栅压只比夹断高 4 mV，C9 那半边 1 秒的慢速分量（见下）会拖出好几 dB 的释放尾巴；真实场效应管在这里是指数导电，平缓得多。n 没有原件数据，取 1.3（亚阈值摆幅约 77 mV/十倍）；n 从 1.3 换到 2.5，慢速释放只变几个百分点。

变压器是理想多绕组变压器加励磁电感和绕组电阻（T1：1.58:1，9 H，45 + 18.4 Ω；T2：1 : 1（反馈）: 0.0465（发射极，√(1.3/600)）: 0.5 + 0.5（输出），初级 6 H，40 / 40 / 30 / 0.2 Ω——绕组电阻和 T2 的电感是估计值）。

### 出厂调整（T+C / PCB 微调），按原厂程序定

| 调整 | 程序 | 结果 |
|---|---|---|
| "Q" 偏置 R59 | G.R. 关，2 kHz，输出比拔掉场效应管时低 1.0 dB | R59 滑臂 0.30677；栅极比 Vto 低 81 mV |
| R30*（输出级偏置） | 选值 | 180k：Q6 33 mA，+30 V 总电流 50.7 mA——原理图上标的就是 "+30V @ 50mA" |
| R86（LN 微调） | 压缩时失真最小 | 35 Ω：二次谐波在这里过零，1 kHz、8 dB 压缩时 THD 0.03 %（0 Ω 时 0.7 %，70 Ω 时 0.76 %） |

## 和原厂规格对比

原厂测试程序是 1990 年的（第 31–38 页），对应后期版本：比率开关 A 组 20:1 那一抽头前面是 R6 1k + T&C，Rev D 是 R78 56k（20:1 少 1.9 dB 侧链信号），所以绝对门限和比率切换量只能参考。

| 项目 | 原厂 | 模型（Rev D） |
|---|---|---|
| 增益（输入输出旋钮最大，600 Ω 负载） | 45 ± 1 dB（UA 规格）；1990：空载、无场效应管 47 dB | 42.7 dB（偏置后），无偏置损失 43.7 dB——低 1–3 dB（T1 / T2 数据是推定的） |
| 门限（1 dB 压缩，2 kHz，输入端） | 4:1 −30，8:1 −26，12:1 −25，20:1 −24 dBu（±2） | −23.4，−21.5，−20，−17 dBu：顺序相同，4:1 到 20:1 相差 6.4 dB（原厂 6 dB）；整体高约 6 dB |
| 比率（门限以上的斜率） | 4、8、12、20:1 | 4.9、8.2、10.9:1；20:1 和"全按"更硬 |
| 比率切换（20:1 在 1 dB 时换到 12 / 8 / 4:1，多压多少） | 1、1.5、2.5 dB | 2.1、2.7、4.2 dB：多出约 1.2 dB，正好是 R78 56k 少的那 1.9 dB 造成的 |
| 启动（10 dB 压缩，2 kHz 短音） | 顺时针 < 20 µs，逆时针 > 800 µs | 顺时针：只有第一个半周过冲，下一个半周已在终值 0.9 dB 内（控制电压 63 % 约 40 µs）；逆时针：63 % 约 0.6 ms，90 % 约 2.6 ms |
| 释放（10 dB 压缩后输入降 20 dB，输出到终值 63 %） | 顺时针 ≥ 50 ms，逆时针 ≤ 1.1 s | 顺时针约 0.1 s（控制电压 τ = 56 ms）✓；逆时针约 1.8–2 s ✗（见下） |
| 失真（压缩中，1.1 s 释放） | < 0.5 % THD（50 Hz–15 kHz） | 41 Hz 0.29 %，55 Hz 0.25 %，440 Hz 0.04 %（4:1，10 dB 压缩）✓ |

**慢速释放比规格长**：LN 网络（R6 = R7 = 2.2M，C9 = 0.22 µF，两张图一致）让栅极只立即跟随控制电压变化的一半，另一半要经 C9 以 τ ≈ (R6 + R7)·C9 ≈ 1 s 跟上。所以每次压缩后都带一段慢尾巴：快速释放时约 0.5 dB，慢速释放时把 63 % 的时间拉长到约 2 s。诊断时把 C9 改成 0.022 µF，两端都正好落在规格上（0.1 s / 1.1 s），说明差别就在这里。电路按原图保留；真机是否同样如此、还是这个场效应管更平缓，没有真机测量没法定论。

## 求解

- 三个 DK 电路，在高阻处分开：A 输入 + 场效应管 + 前级（8 个端口），B 线路放大器（7 个），C 比率网络 + 控制放大 + 整流 + 定时（10 个）。A → B 用电位器滑臂的戴维南等效（精确）；A 的比率网络负载用 C 算出的真实电流修正（晚一个采样，56k 以上）。
- 增益衰减回路（栅极 → 前级 → 侧链 → 控制电压 → 栅极）跨 A 和 C：每个采样内用割线法迭代 A、C 直到控制电压一致（差 < 2 µV）。控制电压只是缓慢漂移时一遍就够；平均每个采样多 0.02–0.03 遍。不迭代的话，最快启动时一个采样的延迟会让控制电压过冲几十 mV。
- 每个电路：Newton 带 SPICE 的结电压限制（pnjlim）、预测器、小步长免复算（1 mV 以内）；直流工作点在一个"直流孪生"电路里求（电容开路、电感短路），按 SPICE 的顺序：直接 Newton → 电源步进 → gmin 步进（每个节点对地 1 mS 降到 10 pS：达林顿中间点只连着结，直流时是浮空的）。
- 采样率：44.1 / 48 kHz 时 2 倍过采样（88.2 / 96 kHz），88.2 kHz 以上不过采样。拨弦序列在 96 kHz 和 384 kHz 之间相差 −57 dB，5 ms 包络最多差 0.01 dB（`comp1176_test null`）。
- CPU（48 kHz，2 倍）：约 13–17 % 单核（重压缩、亮音色时偏高），64 采样缓冲最坏块 32–47 %（实时优先级）。关掉时不占。

## 用在金属吉他上（`comp1176_test metal`）

输入是吉他插孔电压（1 V = 0 dBFS）；1176 是线路电平设备，所以插件里它和录音棚一样接在 reamp 回路里：吉他 → DI + 话放（+20 dB，`Urei1176::kDiGain`）→ 1176 → reamp 盒（−20 dB，`kReampPad`）→ 箱头。两者在门限以下抵消。

**1.0.0 更新**：之前插件里没有前面的 DI，吉他直接进 1176，比它开始压的电平低约 20 dB，用户实测要把 INPUT 拉到接近 10 才压。补上 DI 后，同样的声音需要 INPUT 往下 5.56 格（36 dB 量程里的 20 dB）；旧工程和预设按这个自动换算（`PresetManager.h`，旋钮曲线版本 4；INPUT 不够减的部分从 OUTPUT 的音频锥度上减，那些设置以前基本不压），换算前后电平和压缩量相差 ≤ 0.01 dB（INPUT < 5.56 的极端设置 ≤ 0.4 dB）。

- **门限**（插件里，含 DI；4:1、ATTACK 5、RELEASE 5，降 A 调闷音的平均 / 最大压缩量）：

  | INPUT | 峰值 −18 dBFS（琴颈） | −12 dBFS | −6 dBFS（琴桥用力） |
  |---|---|---|---|
  | 4 | 0 / 0 | 0.9 / 2.6 | 4.6 / 9.8 |
  | 5（默认） | 0.2 / 0.6 | 2.9 / 7.1 | 7.5 / 13.2 |
  | 6 | 1.4 / 4.1 | 5.6 / 11.0 | 10.4 / 16.0 |
  | 7 | 3.7 / 8.5 | 8.4 / 14.2 | 13.3 / 18.6 |

  默认 INPUT 5、OUTPUT 5.3 在门限以下是单位增益。20:1 门限更高（真机就是这样）。下面几条是 `comp1176_test metal` 直接驱动模型（不含 DI）得出的，压缩量相同时结论不变。
- **拨弦起音**：反馈式压缩器，第一个峰值总在侧链反应之前过去——ATTACK 7 也只让拨弦峰值比音体少约 0.8 dB，主要压的是音体（压缩量 2–6 dB，ATTACK 1 时 1–3 dB）。它让演奏力度更均匀，不会把拨弦的颗粒感吃掉。
- **低音弦**：快速释放时控制电压跟着低频波形起伏，产生失真——1176 真机的著名特性。10 dB 压缩下低 E / A（41 / 55 Hz）：RELEASE 7 时 4.5–5.7 % THD，RELEASE 4 时约 0.5 %，RELEASE 1 时约 0.3 %；"全按"模式 RELEASE 7 时约 20 %。
- **闷音 chug（16 分，120 bpm）**：RELEASE 7 时每个音压缩量摆动 8 dB（明显的"喘"），RELEASE 5 时 3 dB，RELEASE 1 时 2 dB。

建议：降调闷音节奏用 4:1 或 8:1、ATTACK 5–7、RELEASE 3–5、压 3–6 dB——更紧、更齐；RELEASE 7 和"全按"是效果用法（颗粒、喘息感）。后面接高增益箱头时，箱头本身已经很压，1176 主要是让拨弦力度更一致、延音更长。

## 和真机 NAM 采样对比（`comp1176_nam`）

TONE3000 上能下载的两个真机 1176 NAM A2 采样（T3K 许可，只在本地用，不再分发）：

| 采样 | 型号 | 已知设置 |
|---|---|---|
| UREI 1176-SF – Fast Control（Tokyo Studio Capture） | 银面板（Rev F 以后：推挽输出级，比率网络不同） | "Fast Control"，其余未标 |
| 1176A Right（tomheavybeats） | "1176 A"：重压时失真很大、释放更快，像没有 LN 电路的 Rev A | 12:1，最快释放，中等启动 |

两个都没有电平校准（数字满刻度对应多少伏未知），也只"记得"约 130 ms（WaveNet 感受野 6205 个采样），所以只能比静态曲线、启动、失真、小信号频响，释放只看头 80 ms。拟合的是能校准的量：输入电平刻度、输出增益、比率、启动、释放旋钮。

| | 银面板 | 1176A |
|---|---|---|
| 最佳拟合 | 4:1，ATTACK 4，RELEASE 7 | 8:1（12:1 只差 0.07 dB），ATTACK 7，RELEASE 7 |
| 静态曲线（1 kHz，−45…0 dBFS） | 0.60 dB rms | 0.45 dB rms |
| 启动包络（1 ms 窗，30 ms） | 0.18 dB rms | 1 ms 内都已压到位，两者一致 |
| 释放（20 dB 降落后 80 ms） | 走势相近（采样有感受野造成的假象） | 采样快：60 ms 回 10 dB，模型 80 ms 回 8 dB |
| 压缩时的失真（1 kHz） | 采样高 10–25 dB（−10 dBFS：H2 −44.5 / −57.7） | 采样高得多（0 dBFS：H2 −25.6 / −48），符合没有 LN |
| 小信号频响 | 采样 20 Hz −5.3 dB、20 kHz −1.3 dB；模型平直 | 采样 ±1 dB 起伏（模型误差），模型平直 |

结论：
- 只调前面板和电平，模型就能贴合两台不同版本的真机到 0.5–0.6 dB rms，启动也对得上。
- 两个采样在 0 dBFS（门限以上约 20 dB）都比模型少压 1.3–1.6 dB；只有最极端的一个点，NAM 在训练范围边缘也最不可靠，没有据此改电路。
- 1176A 释放更快、失真大得多，正是没有 LN 网络（没有 C9 的慢尾巴、没有二次谐波抵消）的表现，反过来支持模型的 LN 部分。
- 银面板压缩时失真比模型高：模型的 LN 抵消对理想场效应管方程是精确的，真机微调后会残留一些；但数值在 NAM 动态误差范围内，没有据此改 R86。
- 20 kHz 的跌落和 20 Hz 的跌落都更像采样链路（48 kHz 录音和训练，20 Hz 跌得比 1176 规格还多）。模型的 −3 dB 点在约 120 kHz（`comp1176_test hf`），1990 年测试程序写约 55 kHz，但那是运放输入的后期版本，同样没有据此改。

所以 Rev D 的电路参数保持不变。能改变结论的是：有电平校准、注明旋钮设置的 Rev D（或复刻版）录音对。

## 没有建模 / 待定

- T1 / T2 的匝数比来自替换件数据，绕组电阻和 T2 电感是估计值；铁芯饱和、漏感没有建模。
- Q1 的亚阈值斜率 n、R45 和 TA 处的 T+C、R83 没有原件数据。
- 1176 自身的噪声（规格：大于 81 dB 信噪比）、G.R. 表头电路、立体声联动。
- 没有真机录音可以对比（只有原厂规格和测试程序）。
