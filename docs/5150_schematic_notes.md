## 3. Rhythm（CLEAN/BLUE）前级网络：N1 → K2A(3)（按出厂原理图核对，v0.5 之后）

出厂原理图第 1 页（400–900 dpi 放大）逐线核对的结果：

```
V1A → C6 → N1 ─┬─ Lead 网络：R29 470k ‖ C17 2.2n → R41 1M、VR2 1M（C19 1n ‖ R40 1M）      两个网络始终都接在 N1 上
               └─ K4A：静止 R19 470k ‖ C51 270p │ 吸合（crunch）R43 2.2M ‖ C13 470p → A
                    A → R21 1M ‖（C10 470p + R75 2.2M；BRIGHT 时 S1C 短路 R75）→ B
                    B = VR1 "Clean Pre" 1M 上端，C27 180p 跨接到滑臂
                    K4B 静止：R23 39k + C63 0.1µ 从 B 到地；吸合时断开
K2A 选择哪个滑臂（VR2 或 VR1）经 R82 470k 到 V1B 栅极
```

继电器状态怎么判断：
- K1C / K2C 线圈和红色 LED（LEDRD2）、通道开关 S2A 串联：按下 Lead 时线圈通电、红灯亮 → **K1 / K2 吸合 = LEAD（RED）**，图上画的静止状态是 Rhythm
- K4C 线圈由 S1A 经 R39 820Ω 接地 → **K4 吸合 = crunch（BLUE）**
- S1 是面板上的双联按键（12 脚，两个 DPDT 按钮，零件名 DRASW）：1–6 脚（S1A、S1D）是 CRUNCH 按钮，7–12 脚（S1B、S1C）是 **BRIGHT** 按钮；S1B、S1D 两段没有用。所以 S1C 短路 R75（C10 470p 直接跨在 R21 上）属于 BRIGHT，和 crunch 无关。6505 面板上 BRIGHT 和 CRUNCH 本来就是两个独立的按键，2dor 的捕获表里四种组合都有
- v0.5.2 之前的模型把 S1C 当成 crunch 的一段：BLUE 总是带 bright，CLEAN 总是不带。现在 BRIGHT 是单独的开关（插件里的 BRIGHT 按钮，默认开），三个通道的电路里都有：rhythm 网络始终挂在 C6 上，所以真机上 BRIGHT 对 LEAD 的高频也有一点影响

增益对比（1 kHz）：CLEAN 的 R19 → R21 1M → 39k 分流约 -30 dB；crunch 的 R43 ‖ C13 → R21 → VR1 1M 约 -7 dB。两者差约 23 dB，和"crunch 增益更高"一致，说明静止 / 吸合的判断是对的。

之前的模型（v0.5.0-beta 及以前）只有 R19 ‖ C51、R23 + C53 分流和 VR1 + C27：没有 R21、C10 / R75，crunch 时也用 R19 而不是 R43 ‖ C13，也没有算另一个网络在 N1 上的负载。现在按上图实现（`FullPreamp5150.h` 的 `Front5150`）。
标号说明：重绘图上的 "C53" 在出厂图上是 C63。

后来拿到了出厂原理图（`EVH 120 preamp bd.`），这一块和重绘图一致。现在 `Preamp5150` 的音色堆栈**只用上表的出厂网络**（`spice/5150_tonestack.cir`，和 LTspice 误差 < 0.01 dB）。之前的经验网络、拟合的 60 pF 低通和 Post 的 -21 dB 修正都删掉了：R89 470k 对 R24 33k 的分压本身就是那 -21…-24 dB，Master 现在直接是电位器曲线。

和 14 个 NAM 捕获比，按原理图实现有一条**和旋钮无关的固定偏差**：高频约 +3 dB、中频约 -2.5 dB（各捕获之间的差别只有 0.2–0.4 dB）。试过的解释都不成立：

| 假设 | 结果 |
|---|---|
| 输出变压器初级分布电容偏大 | 最好 20 nF（实际变压器不可能这么大），RMS 1.19 dB，形状也不对 |
| 捕获链（负载箱 / 声卡）在 5–6 kHz 有低通 | RMS 约 1.2 dB，同样只解释一部分 |

一条和旋钮无关、各捕获一致的偏差，更像是捕获链（Suhr Reactive Load、录音接口）的染色，而不是电路本身。之前的经验网络把这条染色"拟合进了"音色堆栈，代价是旋钮之间的关系不再是真实电路的。决定：**保留出厂电路**，NAM 在频响上只作参考，不再拟合（见 [nam_calibration.md](nam_calibration.md)）。

## 高压电源链（出厂原理图第 2 页）

```
变压器 350 VAC → 桥式整流 CR8–CR11 → PLATE: C34 + C38 330µ 串联 = 165µ     6L6 屏极 / 输出变压器中心抽头
  → R210 400 Ω → SCREEN: C35 + C39 100µ 串联 = 50µ                          6L6 帘栅
  → R59 4k     → V3+: C36 47µ                                               倒相 V4A/V4B
  → R60 22k    → V2+: C37 22µ                                               V2B V5B V5A V3A V3B
  → R61 10k    → V1+: C33 22µ                                               V1A V1B V2A
```

**为什么是 320 V 左右**：每一节 RC 都是"降压 + 滤波"。怠速时 6L6 和帘栅电流让 PLATE 在约 488 V、SCREEN 约 480 V；倒相级（约 3.3 mA）和整个前级的电流共约 9.2 mA 流过 R59 4k，降到约 445 V；然后 V2+ 上 5 个半管（约 4.2 mA）和 V1+ 上 3 个半管（约 1.6 mA）共约 5.8 mA 流过 R60 **22k**，降掉约 128 V 到 **317 V**；V1+ 的 1.6 mA 再经 R61 10k 降到 **301 V**。R60 22k 是整个前级电压低的主要原因；这样做的目的是让前级的纹波（越往后级 RC 滤得越干净）和功放的大电流隔离开，高增益前级不至于嗡。论坛实测的 300–350 V 正好落在这个范围。

模型（`Supply5150`）：电源变压器（空载 374.5 VAC、绕组电阻 41 Ω、60 Hz，见 [power_amp.md](power_amp.md)）经桥式整流给 PLATE 充电，只在市电峰值附近导通，所以 B+ 带 120 Hz 纹波，下垂取决于绕组电阻和导通角（v0.5.1 之前是假设的"500 V 直流 + 60 Ω"，满功率时下垂只有现在的一半）。每个节点一个电容（含泄放电阻），每个采样用各级实际电流积分（显式欧拉，最快的时间常数是绕组电阻进储能电容，约 6.8 ms，至少约 1300 个采样）。时间常数：V3+ 188 ms、V2+ 484 ms、V1+ 220 ms、SCREEN 20 ms。所以重度失真时前级电压也会被拉低，恢复要几百毫秒（"呼吸"感）。`prepare()` 用外层迭代把直流工作点算准（电源冻结、各级电流取平均、解直流，重复几次），开机没有冲击。
和 LTspice（`spice/5150_power_amp*.cir`，同一变压器、整流桥和电源链，前级当作电流源）比：怠速 B+ 488.1 / 487.6 V（LTspice 是纹波的平均值），满功率下的喇叭电压误差 ≤ 0.25%。

## 模型简化（以后要补的）

- V3B 阴极跟随器的信号没有建模（在 Post 之后推效果回路，正常 Master 下是线性的），只算它的屏流（V2+）。V3A 恢复级已经在功放 DK 电路里
- RED 和 BLUE 都是整个前级联立求解（`FullPreamp5150`，6 支管子 12 个端口），按各自的继电器位置连接；两个增益网络都接在 C6 后面（没被选中的那个只是负载）
- CLEAN 是我们"优化"的 6505 清音（V2A–V5A 旁路，不是原机）：V1A + V1B 联立（`CleanPreamp5150`），音色堆栈的源阻抗按 V1B 的输出阻抗算

## CRUNCH 开关（v0.5.4 之后）

插件的 BLUE 通道现在有 **CRUNCH** 按钮（默认开，BLUE 和以前一样）。关掉就是 6505 Rhythm 不开 crunch：K4 静止，R19 470k ‖ C51 270p 和 R23 39k + C63 0.1µ 分流接入，仍然经过全部 5 级（`FullPreamp5150 (channel5150::Clean)`，就是和 2dor [PRE] 捕获对比用的那个电路）。切换和换通道一样：两个电路交叉淡化 20 ms，新电路接过旧电路里相同元件的状态（`amp_path_test switch`：开 → 关 -26.8 dB、关 → 开 -25.6 dB 的杂音，和两个一直运行的电路交叉淡化的理想值 -26.3 / -25.9 dB 一样）。
