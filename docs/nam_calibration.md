# 用真实音箱的 NAM 捕获校准

工具：`tests/nam_compare.cpp`（目标 `nam_compare`），自带标准 NAM WaveNet 推理，不依赖 NAM 库。

```
nam_compare <model.nam>                  按捕获名称里的旋钮刻度对比
nam_compare <model.nam> --fit            网格搜索最匹配的前级 Gain 和功放推动电平
nam_compare <model.nam> --wav <目录>     渲染 WAV 试听（_nam = 真机，_ours = 插件）
```

## 数据

[TONE3000：Peavey 6505 1992 Original (11.5dBu)](https://www.tone3000.com/tones/peavey-6505-1992-original-115dbu-6013)，作者 OutmodedElectronics。
6505 就是改名后的 5150，这台是 Peavey 按 1992 年电路复刻的版本（输出变压器和 6505 II 复刻版相同，不是 1992 原装件）。
链路：DIYRE L2A reamp → 6505 → Suhr Reactive Load → Steinberg UR824（11.5 dBu）。只有箱头，没有箱体。
捕获文件的许可不允许再分发，仓库里不包含，需要自己下载 A1（Legacy）格式的模型。

用到的 6 个模型（全部 Lead 通道、Post 3、不接踏板）：

| 模型 | 用途 |
|---|---|
| Ld Pr-2 / 3 / 4 / 5，B-6 M-4 T-6 R-9 P-8 | 只有前级增益不同：拟合 Gain 和 Master 曲线 |
| Ld Pr-3 B-6 M-6 T-6，R-6 P-6 和 R-8 P-8.5 | 只有 Presence / Resonance 不同：看高频 |

标定：接口电平 11.5 dBu 指满幅正弦的有效值，即 NAM 输入 1.0 = 吉他插孔 4.12 V 峰值；插件约定 0 dBFS = 1 V。
负载箱线路输出的电平未知，所以只比较形状：一次全局电平匹配后的 1/3 倍频程频谱、110 Hz 正弦的谐波和压缩曲线。
把输入标定改动 ±3 dB，结论不变。

## 发现和校准

**v0.3 的 Master 推得太狠。**按"10% 对数电位器"换算 Post 3，插件的功放接近方波（0.3 V 正弦 H3 -11 dB，真机 -20.5 dB），8–12 kHz 高 5–20 dB。降低前级增益不改善，降低功放推动才改善，所以问题在功放这一侧。

**拟合**（`--fit`，同时搜索前级 Gain 和功放推动电平）：

| 捕获 | 最匹配的前级电位器分压比 / 10% 对数曲线 | 功放推动 / 10% 对数曲线 |
|---|---|---|
| Pre 2 | 碰到搜索下限，不采用 | — |
| Pre 3 | 0.43（-7.3 dB） | -21.5 dB |
| Pre 4 | 0.41（-7.7 dB） | -21.0 dB |
| Pre 5 | 0.44（-7.1 dB） | -20.0 dB |

三个点非常一致，校准为（`Preamp5150.h`）：
- 前级 Gain：更陡的对数曲线 `(10^(2.65x) - 1) / (10^2.65 - 1)`，转到一半约 4.5%（10% 对数曲线是 9%）
- Master：同一条曲线 × 0.229，Post 3 时比 10% 对数曲线低约 21 dB

根本原因是电位器曲线还是电路里其他地方增益偏高，这组数据分不出来（只有 Post 3 一个点）；校准后旋钮刻度和真机读数一致。

**校准后**（直接把旋钮拧到捕获的刻度，0.3 V 正弦，dB re 基波）：

| | H3 | H5 | H7 |
|---|---|---|---|
| v0.3（Pre 5） | -11.1 | -17.8 | -23.9 |
| 现在（Pre 5） | -19.5 | -30.6 | -32.7 |
| 真机 | -20.5 | -29.1 | -30.6 |

## 中频 / 高频偏差：音色堆栈、Presence 还是固定元件？

Gain / Master 校准后频谱平均差还有 2.0–3.9 dB：500 Hz–2 kHz 偏少 3–6 dB，12.5 kHz 偏多 2–7 dB。
为了分清是哪个旋钮的问题，又下载了 8 个 EQ 不同的捕获，一共 14 个（Bass 5–10、Mid 2–6、Treble 5–7、Presence 5–8.5、Resonance 5–10）。

方法（`nam_compare --residual` 输出每个捕获在每个 1/3 倍频程的偏差）：对每个频带做线性回归
`偏差 = 常数 + a·Bass + b·Mid + c·Treble + d·Presence + e·Resonance`，
常数项是和旋钮无关的固定偏差，系数显著不为零说明那个旋钮建模有问题。回归的拟合残差只有 0.1–0.4 dB，线性模型够用。

**结果：旋钮系数都很小**（每格 ≤ 0.3–0.4 dB），音色堆栈和 Presence 的电位器曲线基本是对的。
Presence 略弱、Bass 略强，在这些捕获的旋钮范围内累计不到 1 dB，没有改。

**偏差主要是一条和旋钮无关的固定曲线**（我们 − 真机，dB）：

| 63 Hz | 250 Hz | 800 Hz | 2 kHz | 4 kHz | 8 kHz | 12.8 kHz | RMS |
|---|---|---|---|---|---|---|---|
| +1.9 | -0.7 | -2.7 | -1.7 | -0.1 | +3.1 | +5.6 | 2.17 |

指向信号通路里的固定元件。试过的假设：

| 假设 | 结果 |
|---|---|
| 前级每个栅极的对地杂散电容 | 45 pF 也只改变 0.5 dB，排除 |
| V3B 阴极跟随器栅极 R89 470k + C60 对地（原理图笔记里有 C60 100 pF，模型里没有） | 高频形状吻合，等效 50–70 pF 最好，100 pF 过头 |
| 箱体阻抗谐振峰太高（v0.3 是 6+39 Ω） | 低频多出的 2–3 dB 来自这里，降到 6+4…8 Ω 最好 |

两个参数在网格上联合扫描（谐振峰 4–16 Ω × C60 40–80 pF），最好的区域是 4–8 Ω、60–70 pF，固定偏差 RMS 从 2.17 降到 0.60 dB（所有频带 -1.0…+1.1 dB）。采用 **8 Ω、60 pF**：
- `Preamp5150`：音色堆栈前加 R89 470k + C60 等效 60 pF 的一阶低通（截止约 4.9 kHz）
- `PowerAmp5150::kSpeakerPeakR`：8 Ω；LTspice 网表同步修改并重跑，C++ 和 LTspice 依然吻合（见 [power_amp.md](power_amp.md)）

要说明的两点：
- C60 文档值是 100 pF，拟合出的等效值 60 pF 说明它的实际位置或驱动阻抗和假设不完全一样（原理图这一块最模糊）
- 谐振峰匹配的是捕获用的 Suhr Reactive Load，不一定代表每个真实 4×12。用户加载的箱体 IR 不包含"功放-喇叭"的阻抗互动，所以这里选了一个真实负载箱的特性

**最终结果**（14 个捕获，旋钮直接拧到捕获的刻度）：
- 频谱平均差 0.95–1.99 dB（之前 2.0–3.9 dB；v0.3 按旋钮换算是 2.0–4.5 dB 且 12.5 kHz 高 15–20 dB）
- 0.3 V 正弦奇次谐波：H3 多数在 ±2 dB 以内（最差 4.3 dB），H5 / H7 多数在 ±3 dB 以内

## 还没解决的

- 真机的偶次谐波（H2、H4）在不同设置下和插件有几 dB 到十几 dB 的差别，说明真机前级的不对称性和我们不同
- Pre 很低、输入很小（3 mV）时，真机已经有明显失真（H2 -31 dB），插件几乎干净
- 数据只来自一台 6505、一个负载箱、Post 都是 3。NAM 在能量很低的高频段本身也可能有几 dB 误差
