# 电路噪声（v0.5.4 之后）

插件里箱头区的 **NOISE** 开关（默认关）：前级自己的噪声，按物理算，不是加一段录好的底噪。

## 模型

**电阻的热噪声**（Johnson 噪声）：每个噪声电阻上并一个噪声电流源，谱密度 4kT / R（T = 300 K），白噪声一直到奈奎斯特频率。它在电路里和信号一起被求解（`DKCircuit::addR (…, true)`、`setNoise`），所以电阻的噪声经过哪些分压、电容、反馈，就被怎样衰减或放大，不需要手算每一级的等效噪声。带串联电阻的源（输入的 R27、各级屏极负载）在源电压上加 4kT · R 的串联噪声。

加了噪声的电阻：输入（R27、R25、R22），两个增益网络（R29、R41、R40、VR2，R19 / R43、R21、R75、VR1、R23），各级的栅极电阻和栅漏电阻（R82、R6、R9、R20、R7、R11、R32、R101、R87、R91、R88），不旁路的阴极电阻（R15、R102、R93），屏极负载。没加的：有电容旁路的阴极电阻和输出端的负载，它们的噪声在音频范围里被旁路或在信号之后，可以忽略。

**电子管噪声**（`TubeNoise`），折算到栅极的电压，只作用在屏流上（栅流仍按真实栅压）：
- 散粒噪声：三极管的等效噪声电阻 Req = 2.5 / gm（教科书的值），gm 取每一级自己的直流工作点；
- 闪烁噪声（1/f）：转角频率 5 kHz，即密度 4kT · Req · (1 + fc / f)。用半个十倍频程一个的一阶低通滤波器组生成，20 Hz–20 kHz 内和 1/f 的偏差约 ±0.3 dB。

5 kHz 的转角是唯一的假设：管子之间闪烁噪声差好几倍。用它算出的 12AX7（gm 1.25 mA/V）在 25 Hz–10 kHz 是 1.14 µV，在 12AX7A / 7025 的规格"折算到栅极的噪声和交流声，平均 1.8 µV"（含交流声）以内。

功放（V3A、倒相级、6L6）和交流声、颤噪效应没有建模：功放的噪声在前级的增益后面可以忽略；交流声和颤噪的大小没有可靠的数据。

## 验证（`dsp_test noise`）

噪声发生器（折算到栅极，nV/√Hz，模型 / 目标）：

| 频率 | 100 Hz | 1 kHz | 5 kHz | 20 kHz |
|---|---|---|---|---|
| | 39.8 / 41.1 | 14.1 / 14.1 | 8.2 / 8.1 | 6.4 / 6.4 |

整个前级（输入短路，音色堆栈 + Post 5），折算到输入、1 kHz 的噪声密度：

| 通道 | Gain 2 | Gain 5 | Gain 8 |
|---|---|---|---|
| RED | 47.5 | 42.1 | 41.8 nV/√Hz |
| BLUE | 268 | 55.2 | 44.0 nV/√Hz |
| CLEAN | 2494 | 327 | 71.4 nV/√Hz |

手算 V1A 栅极一处（R27 ‖ R25 + R22 68k + 管子）是 41.0 nV/√Hz，和 RED 高增益时的 41.8 一致：高增益时噪声几乎全来自第一级。Gain 低时增益电位器在 V1B 之前把信号衰减了，后面几级（特别是 R82 470k 和 V1B）的噪声占主导，折算到输入就变大；真机也是这样，5150 把 Gain 关小，嘶声不会按比例变小。

RED 在 Post 5 时前级输出的噪声是 0.07–0.44 mV rms（Gain 2–8），约比饱和信号低 57–63 dB。

## 实现和开销

`DKCircuit` 给每个噪声电阻多一个输入（注入电流），矩阵在 `prepare()` 里就包含这些列，开关噪声不改变电路结构；噪声关闭时这些输入为 0，结果和以前逐位相同（`tone_regress` 不变）。噪声样本用 xorshift 的均匀分布（同样的方差；经过电路以后分布无关紧要），每个电路一个独立的种子。
