# 5150 功放元件级模型

代码：`Source/dsp/PowerAmp5150.h`（电路）+ `Source/dsp/DKCircuit.h`（求解器）
LTspice 参考：`spice/5150_power_amp.cir`、`spice/5150_power_amp_drive.cir`、`spice/6L6GC.inc`

## 电路（原理图第 3–4 页）

```
Master → V3A 恢复级 (R5 68k, R14 3.3k ‖ C61 4.7n)
       → C49 22n → 长尾对倒相 V4A/V4B (R46 82k / R58 100k, R52 470, R51 10k, R57 4.7k, R48/R50/R53)
       → C28/C29 47n, R54/R55 220k 偏置, C201/C202 100p 对地, 2.2k 栅极阻尼
       → 2 × 2 × 6L6GC 推挽 (CR200/CR201 回扫二极管; 极间电容按手册: 输入 10 pF、栅-屏 0.6 pF)
       → 输出变压器 (Raa ≈ 2.1k, 8 Ω, 磁化电感 30 H, 初级分布电容 2.5 nF)
       → 4×12 喇叭阻抗 (Vintage 30：Re 7.3 Ω、音圈 0.7 mH ‖ 涡流损耗 6 Ω（经验拟合）、箱内谐振 85 Hz、谐振峰 24 Ω，见"喇叭负载"和"高频：音圈损耗的经验拟合")

负反馈: 喇叭 → R56 39k → (C12 6.8n ‖ VR8 Resonance 1M) → Y → C30 22µ → 尾部节点 L（R57 4.7k）
Presence: Y → VR9 10k (对数) → C8 0.1µ ‖ C62 0.033µ → 地;   V4A 栅极经 C31 47n 以 L 为交流参考
电源: 电源变压器高压绕组 → 桥式整流 CR8–CR11 (1N4007) → PLATE (165µ, 泄放 R62+R64) → R210 400 Ω
      → SCREEN (50µ, 泄放 R63+R65) → R59 4k → V3+ 倒相 (47µ)
      → R60 22k → V2+ (22µ, V3A V3B 和 V2B V5B V5A) → R61 10k → V1+ (22µ, V1A V1B V2A)
      每个节点带下垂，前级的电流也算进去 (Supply5150)
```

**Presence 网络（v0.5.1 之后修正）**：原理图上 C8 0.1µ 和 **C62 0.033µ** 并联，VR9 标的是 **10KA（对数）**，滑臂和电容那一端接在一起，当可变电阻接地。之前模型只有 C8、而且用线性锥度：Presence 7 时电路里只剩 3k（真机约 7.6k），Presence 推得太多，高频偏亮。修正后和真机功放捕获的小信号频响误差从 2.0 dB 降到 1.1 dB（见下文"和真机功放对比"），也解释了 [nam_calibration.md](nam_calibration.md) 里"和旋钮无关的高频 +3 dB"的大部分。

**整流（v0.5.1 之后修正）**：之前把整流当成"500 V 直流源 + 60 Ω"。真机是变压器加桥式整流：储能电容只在市电峰值附近被充电，B+ 带 120 Hz 纹波（怠速约 6 V pp，大力弹约 10 V pp），下垂取决于绕组电阻和导通角。满功率时 B+ 从 488 V 降到约 436 V（1 kHz；低音时喇叭阻抗低，降得更多；之前只到 456 V），大声弹时箱头真正"软下去"；松手后约 100 ms 恢复。纹波在推挽输出端互相抵消：怠速时喇叭端 120 Hz 嗡声约 -120 dB（相对满功率），只在演奏时和信号互调。

## 求解方法

功放里有一个从喇叭回到倒相级的负反馈环。如果按级拆开、用"上一个采样"的值传递，环路里就多了一个采样的延迟，环路增益约 3 倍时会直接振荡发散。所以整个功放（倒相级 + 功率管 + 变压器 + 喇叭 + 负反馈）用 **DK 方法**联立求解：

- 所有线性元件（R、C、L、变压器、电源）合成一个 MNA 矩阵，电位器变化时才重新求逆
- 每个采样只对 10 个非线性端口（V3A 和倒相级 3 支 12AX7 + 2 对 6L6 的屏极 / 栅极）做牛顿迭代；V3A 恢复级也在电路里，直接看到倒相级的真实负载
- 预测器（线性外推）+ 残差判断收敛 + 失败时从上一个解重新迭代；预测器在噪声输入时会自动关闭

## 和真机功放对比（POW 捕获）

工具：`tests/power_compare.cpp`（目标 `power_compare`），`power_compare <model.nam> [--in-dbu 18.995] [--pres 7] [--reso 7] [--probe]`。

数据：TONE3000 上 2dor 的 [Peavey 6505 1992 Original](https://www.tone3000.com/tones/peavey-6505-1992-original-64607) 包里的三个 **[POW]** 捕获。这些捕获：
- 只有功放：信号从效果回路的 Return 进入，所以和前级、Master 无关；
- Presence 7、Resonance 7；
- 用**真实箱体**当负载：Mesa 4x12、Mesa 2x12、Marshall 4x12；
- 有标定：Send 18.995 dBu。

捕获的许可不允许再分发，仓库里不包含。Return 由接口经 Lehle 分配器驱动（源阻抗按 1k，`setInputSourceResistance`）；插件里功放的输入是 Post 电位器的滑臂，约 100k。前级照常怠速运行，因为它仍然从电源取电流。

小信号频响误差（均方根，40 Hz–12 kHz）：

| | Mesa 4x12 | Mesa 2x12 | Marshall 4x12 |
|---|---|---|---|
| v0.5.1 | 2.04 dB | 2.04 dB | 1.92 dB |
| v0.5.2（Presence 网络、真实整流） | 1.07 dB | 1.16 dB | 1.14 dB |
| v0.5.3（6L6 屏极内阻、物理喇叭负载） | 0.67 dB | 0.76 dB | 0.85 dB |
| v0.5.5（VR8 锥度、C201/C202、6L6 极间电容和帘栅电流、喇叭 fc 85 / Qmc 2） | 0.69 dB | 0.58 dB | 0.58 dB |
| 现在（音圈损耗 15 → 6 Ω，经验拟合） | **0.53 dB** | **0.27 dB** | **0.43 dB** |

现在：
- 160 Hz–5 kHz：三个箱体都在 ±1.0 dB 以内（大部分 ±0.5 dB；3–5 kHz 约 -0.3…-0.5 dB）；
- 箱体谐振附近（63–125 Hz）：Marshall 4x12 和 Mesa 2x12 在 ±0.8 dB 以内，Mesa 4x12 的箱体谐振更低，63 Hz -1.3 dB；
- 6 kHz 以上：+0.6…+1.3 dB（之前 +0.7…+3.1 dB，见"高频：音圈损耗的经验拟合"）。

压缩（110 Hz / 1 kHz，0.3–8 V，我们 - 真机），均方根 Mesa 4x12 / Mesa 2x12 / Marshall 0.72 / 0.49 / 0.44 dB（v0.5.3：1.08 / 0.80 / 0.79；v0.5.5：0.63 / 0.54 / 0.50）：
- 1 kHz：-1.0…+0.0 dB；
- 110 Hz：+0.2…+1.2 dB，仍然压缩得比真机少一点（Mesa 4x12 最明显，它的箱体谐振更低）。

**Resonance 的锥度（v0.5.3 之后）**：出厂原理图上 VR8 是 POT0752 "1M 5% A"，和 Gain 电位器 VR1 / VR2 是同一个零件；Gain 早就按真机校准成转到一半约 4.5%（`taperPot`），VR8 却还用一般的 10% 对数律，Resonance 7 时电路里是 244k，真机是 159k，低频反馈少了，低频偏多。改成同一条锥度后，三个箱体在 63–125 Hz 的偏差明显变小（上表）。41 个 Suhr 负载箱 Lead 捕获上，63–100 Hz 的偏差仍随 Resonance 每格增加约 0.5 dB，Resonance 很高时输出阻抗大、低频跟着各自负载的谐振走，一个 4x12 模型对不上所有箱体 / 负载箱。

**C201 / C202 和 6L6 的极间电容（v0.5.3 之后补上）**：出厂功放板上每一侧的栅极馈电点有 100 pF 对地（2.2k 阻尼电阻之前），模型以前没有；6L6GC 的输入电容 10 pF、栅-屏 0.6 pF（手册）也没有。它们和倒相级约 40k 的屏极输出阻抗形成一个约 30–40 kHz 的极点，在负反馈环里面：环路高频增益降低，高频输出阻抗略升，结果 10 kHz 以上反而多了约 0.2 dB。按原理图保留。

### 高频：音圈损耗的经验拟合（v0.5.5 之后）

v0.5.5 时 6 kHz 以上我们比三个真实箱体都多 +0.7…+3 dB（12.8 kHz 约 +2 dB），三个箱体几乎一样。查过、排除了的电路原因：
- Presence：Presence 0 时也多 +1.7 dB；
- 输出变压器漏感：在环路里，只会让高频更多；
- C201 / C202、6L6 极间电容：同上，在环路里，高频略多；
- 反馈取点：出厂原理图上反馈总是取自 8 Ω 抽头，阻抗开关只换喇叭接的抽头，环路增益不变。

喇叭端的高频电压取决于功放输出阻抗和喇叭高频阻抗之比；喇叭拟合一直想把音圈的涡流损耗电阻压低。Celestion 不公布 V30 的阻抗曲线和音圈电感（规格书只有声压曲线、Re 7.3 Ω、Fs 75 Hz），也没找到 4x12 在 5–20 kHz 的实测阻抗。按用户的要求，在拿不到实测数据的情况下做经验拟合：

- **只拟合音圈的高频部分**（`power_compare --fitcoil`）：电感 0.35–2 mH × 涡流损耗 3–15 Ω，箱体谐振（fc 85 Hz、Qmc 2）和 Re 不动。结果 **0.7 mH（不变）‖ 6 Ω**，在网格内部，三个箱体的误差均方根 0.62 → 0.42 dB。12.8 kHz 时喇叭阻抗从约 21 Ω 变成约 13 Ω。
- **用拟合没用过的数据检验**：5 个接真实箱体的整机 LEAD 捕获，8–12.8 kHz 每一个都改善约 1 dB（10 kHz：Sneap +1.9 → +1.0，Mirroring +1.4 → +0.5，Legend +3.1 → +2.2，Ending Heartbrake +3.0 → +2.1，Pink Gator +2.2 → +1.3），2 kHz 附近只变了 -0.1…-0.2 dB。

所以 6 Ω 是默认值。它不是测出来的物理值：如果真正的原因是捕获链路在高频的衰减，这个拟合也会把它吸收进来。有真实箱体的阻抗曲线时应该用实测值替换。

### 6L6 的屏极内阻

Koren 的五极管公式在拐点以上，屏流几乎不随屏压变化（只有 atan 项）：
- 在数据手册的工作点算出 6L6GC 的屏极内阻是 98k / 281k，手册是 22.5k / 33k；
- 在 5150 的怠速点约 890k。

这样输出级自己几乎没有内阻，输出阻抗全靠负反馈，功放就会过度地"跟着喇叭阻抗走"。

加一个 Early 项 (1 + Vpk / Va) 以后，rp ≈ (Va + Vpk) / Ip。两个手册工作点给出几乎相同的 Va（约 1400–1650 V）；KG1 相应调整，让屏流不变。

### 6L6 的帘栅电流（v0.5.4 之后）

Koren 的帘栅电流只和栅压、帘栅压有关，和屏压无关。实际的束射四极管在屏压摆低时（深度削波，尤其是低音、喇叭谐振附近），本该到屏极的电子有一部分回到帘栅，帘栅电流成倍增加，经 R210 400 Ω 拉低帘栅电源：这正是推满时压缩和"软"的一部分。RCA 6L6GC 手册的推挽 AB1（450 V / 400 V / -37 V，栅-栅峰值 70 V，屏-屏 5.6k）：一对管子的帘栅电流从 5.6 mA（无信号）升到 **22 mA（满信号）**。旧模型满信号只有 12.8 mA（-42%），屏流和功率却是对的（199 / 210 mA，53.4 / 55 W）。

修正按电流守恒：Koren 的屏流拐点 atan(Vpk / kvb) 在低屏压时"扣下"的那部分阴极电流，base · (π/2 − atan(Vpk / kvb))，加到帘栅上，再加 Koren 原来的帘栅项。只有一个参数 kg2，对四个手册点做最小二乘：kg2 = 12000。

|---|---|---|---|---|

### 喇叭负载

电子管功放的输出电压会部分跟着喇叭的阻抗曲线走。之前的负载（Re 6 Ω、0.5 mH、谐振峰 6 + 8 Ω）是按 Suhr 负载箱、在旧的 Presence 网络下拟合的。现在按喇叭的物理参数搭：

- **Re 7.3 Ω、Fs 75 Hz**：Celestion Vintage 30 规格。
- **Qes 0.78**：V30 类喇叭的参数（WGS Veteran 30：Fs 95 Hz、Re 8.0 Ω、Le 0.35 mH、Qms 12.2、Qes 0.78、Cms 0.1 mm/N，即 Vas 约 19 L）。
- **箱内谐振**：每只喇叭约 27–35 L 空气，悬挂被压紧，fc ≈ 90 Hz（V30 4x12 用户实测 90–105 Hz）。Qec = Qes · fc / Fs。
- **总机械 Q**：单只喇叭约 12，4×12 远低于这个值，因为箱子漏气、四只喇叭的谐振频率各有偏差（R. Aiken 的测量和讨论）。
- **音圈**：同类喇叭实测 0.35–0.7 mH（G12H-75 是 0.7 mH），加涡流损耗。

动生阻抗由这些算出：Res = Re · Qmc / Qec，Cmes = Qec / (2π fc Re)，Lces = 1 / ((2π fc)² Cmes)。

总机械 Q、fc、音圈电感和损耗这几个未知量，只在各自的物理范围内，用三个真实箱体的功放捕获拟合（`power_compare --fitspk`）。v0.5.3 的结果是 Qmc 3（Res 23 Ω）、fc 90 Hz、0.7 mH ‖ 15 Ω，但当时 Qmc、fc、损耗电阻都停在网格边界上，Qec 也固定成 1.02，没有随 fc 变。VR8 锥度改正后在更大的网格上重拟合（Qmc 2–4、fc 80–95 Hz、0.5–1 mH、10–30 Ω，Qec = Qes · fc / Fs）：**Qmc 2（谐振峰 7.3 + 16.5 = 24 Ω）、fc 85 Hz**、音圈不变 0.7 mH ‖ 15 Ω，三个箱体的误差均方根 0.67 → 0.62 dB。之后音圈损耗按经验拟合改成 6 Ω（见"高频：音圈损耗的经验拟合"）。

**被否决的方案：** 不限物理范围时，最佳拟合是一个几乎平坦的"喇叭"（谐振峰 23 Ω，音圈 2 mH，1 kHz 约 16 Ω）。它的音圈电感是实测的 3–5 倍，用别的未知量补偿了 6L6 屏极内阻的问题，所以没有采用。

**也测试过、没有采用：** 输出变压器漏感（10–40 mH）。反馈取自漏感之后的喇叭端，漏感只会让高频输出阻抗更高、更跟着喇叭走，结果更差。

**手感（音头和松手）**：110 Hz，0.3 V → 3 V 或 8 V → 0.3 V，每 5 ms 的电平。
- 松手后，真机和我们都先"闷"一下（-14…-17 dB），这是功放管和倒相级被栅流偏移造成的阻塞。
- 但真机约 25 ms 就回来了，我们晚约 10 ms：8 V 之后 25 ms 时，我们 -13 dB，真机 -1…-2 dB。

`--probe` 显示阻塞来自倒相级的输入管 V4B：
- 大声时它的栅极经 R48 100k 导通，给 C49 22n 充电，平均偏置从 -1.7 V 掉到 -19 V（3 V）或 -43 V（8 V）；
- 松手后 V4B 截止约 20 ms（C49 经 R50 1M 放电，τ ≈ 23 ms），倒相级严重失衡，两对 6L6 的栅极一边到 -4 V、一边到 -145 V。

试过把 6L6 栅流模型的电阻从 1k 改到 10k，结果完全不变：栅流被倒相级约 40k 的输出阻抗限制。这些元件值都和原理图一致，所以没有为了贴合捕获去改。

**和 LTspice 逐周期对比（v0.5.4 之后）**：同一个 burst（110 Hz，0.3 V → 8 V → 0.3 V，1k 源，Presence / Resonance 7），LTspice 网表用和 C++ 完全相同的器件方程（`12AX7_cpp.inc` 的栅流、6L6 同一条栅流曲线），每个周期比喇叭端 RMS 和 V4B 的平均栅偏压。松手后第 1 / 3 / 5 个周期：LTspice 7.36 / 25.82 / 40.36 V，C++ 7.40 / 25.46 / 40.24 V；第一个周期 V4B 偏压 -20.49 / -20.67 V；192 kHz 和 384 kHz 结果一样。所以约 35 ms 的恢复就是原理图上这些元件给出的，求解器在剧烈的阻塞瞬态下也是对的。前级做了同样的检查（LEAD，20 mV → 0.5 V → 20 mV）：V2B 屏极松手后从 92 V 回到 166 V 约 100 ms，C++ 和 LTspice 每个周期都在 0.1% 以内。（草稿工具：`scratchpad/stages/burst_cpp.cpp`、`pburst_cpp.cpp` 和对应网表，没有放进仓库。）

NAM 捕获在 10–40 ms 这种阻塞动态上也不完全可信：8 V 音头处真机（捕获）是先小后大，物理上应该先大、等栅极充电后再压下去（我们是这样）。要确定需要真机的 reamp 录音。这些 A2 模型的记忆约 130 ms（感受野 6350 个样本），所以电源链里前级电压几百毫秒的恢复它们表现不了。

## Master 旋钮

v0.4 起 Master（以及前级 Gain）按真实 6505 的 NAM 捕获校准，刻度和真机一致，见 [nam_calibration.md](nam_calibration.md)。真机在 Post 3 时功放只是轻度饱和，送进功放的电平比"10% 对数电位器"的假设低约 21 dB。

v0.3 用的是 60 dB 对数曲线（"Master 1 干净、2 开始压缩、3 饱和"），比真机推得狠得多，这是当时削波偏硬、高频偏亮的主要原因。旧工程和旧预设读取时会按相同的电位器分压比换算，声音不变。

## 求解器收敛

v0.3.0 给栅极端口的 Newton 步长限制是 4 V。RED 通道前级的陡峭边沿经 C28/C29 会让 6L6 栅极在一个样本内摆动 100 V 以上，46 次迭代也走不到解；不收敛的样本输出错误值，喇叭端出现最高约 300 V 的尖峰（Master 高时可闻的爆音）。现在栅极和屏极共用 40 V 限制：栅流和续流二极管都是 softplus 拐点（拐点以上是线性的），越过去的一步下一次迭代就会自己修正，测试中 0 次不收敛。

## 异常样本的处理

非有限值（NaN / 无穷）或求解失败的样本按"丢了一个输入样本"处理，不再把电路状态清零：

| 层 | 遇到什么 | 怎么处理 |
|---|---|---|
| 插件入口（`PluginProcessor`） | 宿主送来的非有限输入 | 用上一个有限样本代替。否则会永久污染变调、压缩、过采样滤波器、箱体、延迟和混响的状态，直到重新加载插件 |
| 每个三极管级（`TriodeStage`，含 V3A） | 非有限输入 | 用上一个被接受的输入代替，正常求解 |
| 每个三极管级 / 功放 DK 求解 | 解非有限或超出范围 | 用上一个被接受的输入重解一次；还失败就丢弃这个样本：状态保持上一个样本，输出重复上一个值 |
| 同上 | 连续失败超过 1 ms | 三极管级回到静态工作点；功放回到 `prepare()` 时保存的稳定怠速状态（不是全零） |

v0.4 的做法是直接重置：三极管级回到静态工作点、功放把所有电容状态清零。演奏中这相当于耦合电容和电源电容瞬间放电。
`dsp_test fault`（RED Gain 5、Master 6、352.8 kHz，0.4 s 处注入一个坏样本，和无故障渲染比较，20 kHz 以下）：

| 情况 | v0.4 最大偏差 / 持续 | 现在 |
|---|---|---|
| 前级输入 NaN / inf | 115 V / 24.6 ms | 0.07 V / 0 ms |
| 功放输入 NaN / inf | 10.2 V / 6.6 ms | 0.00 V |
| 单次求解失败（测试钩子 `testFaults`） | 同上 | 0.07 V（V1A）/ 0.00 V（功放） |
| 重解也失败（只能保持状态） | 同上 | V1A 4.3 V / 0.25 ms；功放 0.05 V |

下限是"把这个输入样本换成上一个样本"本身造成的偏差（0.07 V，干净渲染峰值 60 V）：坏样本里没有信息，任何处理都不可能比它更好。
跳过一次状态更新比替换输入差得多（V1A 4.3 V），因为梯形法的电容等效电流源会把两个样本的电压变化当成一个样本，经 Cgp / Cgk 产生一个样本的电流尖峰，后面的高增益级把它放大；所以它只是最后手段。
另外测了极端但有限的输入：1 kV 尖峰（同上设置），以及 2 s 的 100 V 正弦（Gain、Master、Presence、Resonance 全开）。输出都有限，喇叭峰值分别为 60.0 V 和 60.7 V，0 次不收敛。

**不收敛的解（v0.5.4 之后）**：之前 Newton 用完所有迭代还没收敛时，只要数值有限就直接接受；一个错得很远但有限的状态会被当成正确结果（爆音）。现在不收敛的解只有在接近解（端口方程残差 ≤ 10 mV，约为容差的 500 倍，仍然听不出来）、而且每个端口电压在物理范围内（屏压 -500…1500 V，栅压 -1000…100 V）时才接受，否则走上面同一条"重解 → 保持 → 回到怠速"的路。前级（`TriodeNetwork`）和功放（`PowerAmp5150`）都一样。

测试钩子 `testCorrupt` 让一次求解以"不收敛、偏 300 V"结束：有这个检查时偏差为 0（重解成功）；把检查关掉，RED 前级出现 74 V 的偏差、持续约 600 ms。

**持续故障**：求解器连续失败 2 ms（超过 1 ms 的保持时间，电路回到怠速点）。输出始终有限，峰值不超过干净渲染（RED 57.4 V），20–83 ms 后回到干净渲染的 1% 以内（前级的阴极 / 耦合电容要重新建立）。这三个情况和上面的一起在 `dsp_test fault` 里。

正常信号下这些分支都不会触发：3 个通道 × 3 个 Master × Drive 开 / 关，共 320 万个样本，输出和改动前逐字节相同；`tone_regress` 结果不变；CPU 差异在测量噪声以内。

## 旋钮变化

Presence、Resonance（以及 RED 的 Gain）是 DK 电路里的电阻：改动后要重建电路矩阵。重建以前在音频线程上分配内存，现在所有工作缓冲区在 `prepare()` 里分好，重建不再分配（`DKCircuit`，结果逐字节不变）。

旋钮值每个宿主 block 才送来一次，直接用会在每个 block 边界跳一下（拉链声，buffer 越大越明显）。现在 `AmpSim` 让目标值在 block 内从上一个 block 的值线性过渡到新值，每个旋钮再以约 20 ms 的一阶平滑跟随它：Master、音色、Drive 每 32 个过采样样本更新一次，Gain / Presence / Resonance（要重建矩阵）每 128 个（约 0.36 ms，一次 20 ms 的变化仍有约 55 步）。
只有一阶平滑、没有 block 内的线性过渡时，目标值是每 block 一跳的台阶，旋钮的速度在 block 频率（512 样本时 94 Hz）上一冲一冲，产生边带：Resonance 0 → 1 在 512 样本 block 时 -47 dB，目标值完全平滑时是 -59 dB。

`amp_path_test knobs`：220 Hz 正弦，旋钮 0.4 s 内自动化变化，谐波之间的杂音能量（dB re 总能量）：

| 旋钮 | 512 样本 block，只有线性过渡 | + 20 ms 平滑 | 64 样本 block，+ 20 ms 平滑 |
|---|---|---|---|
| Master 0.2 → 0.6 | -51.0 | -58.9 | -57.7 |
| Gain 0.3 → 0.7 | -48.7 | -50.5 | -50.4 |
| Presence 0 → 1 | -36.6 | -60.5 | -60.0 |
| Resonance 0 → 1 | -52.3 | -59.8 | -58.8 |

（旋钮不动：-63 dB。v0.5.1 之前是 -89 dB：现在的底噪是 B+ 的 120 Hz 纹波和信号互调出来的边带，真机也有。Presence 改成对数锥度后，"只有线性过渡"那一列变差，因为电阻主要在旋钮的最后 30% 里变化；插件实际用的是 + 20 ms 平滑那一列，和底噪差不多。）现在和 buffer 大小无关。Gain 的约 -46 dB 和 block 大小、平滑都无关，用参考精度和冻结电源测也一样：那是 Gain 变化时前级波形和冷偏置跟着变的真实响应，不是拉链声。
（tier 1 时记录的数字更好，-52…-75 dB，但那是在出厂音色堆栈、电源链之前测的，现在的电路对这些旋钮的反应本身就不同：用参考精度、冻结电源、目标值完全平滑都复现不了当时的数字。）

## 切换通道

三个通道在模型里是三个电路（RED、BLUE 各一个 `FullPreamp5150`，CLEAN 一个 `CleanPreamp5150`）；真机上是同一组电子管，继电器改接几个网络，所有电容保持电荷。所以切换时：
- 新通道的电路**接过旧通道的状态**：同一个元件（电子管的端口电压、耦合 / 阴极 / Miller 电容）原样复制，只有两个通道不同的元件（例如 C51 和 C13）从静态点开始（`warmFrom`）
- 被改接的网络本身还是一下子变了，音色堆栈的源也跟着变，所以两个通道同时运行 20 ms 交叉淡化（每个通道带自己的电平修正，CLEAN 的 54 倍不会把 RED 在淡化中途放大），音色堆栈的源阻抗也跟着滑过去
- `prepare()` 之后还没出过声音时切换是立即的（没什么可淡化）

`amp_path_test switch`：220 Hz 0.1 V，切换前目标通道先用过、再被切走 1 s；比较的"理想"是两个一直在运行的前级交叉淡化后送进同一个功放（功放在推动量变化时自己的重新偏置两边都有）。dB re 总能量：

|---|---|---|---|
| RED → CLEAN | -1.3 / -10.9 | -22.8 / -20.3 | -23.5 / -20.4 |
| CLEAN → RED | -14.5 / -19.8 | -21.5 / -18.3 | -22.7 / -18.7 |
| RED → BLUE | -18.6 / -24.3 | -26.7 / -27.9 | -31.6 / -40.2 |
| BLUE → RED | -19.8 / -37.9 | -30.0 / -37.8 | -31.6 / -39.8 |
| BLUE → CLEAN | -1.4 / -11.9 | -23.9 / -20.9 | -24.0 / -20.8 |
| CLEAN → BLUE | -10.7 / -13.6 | -23.1 / -19.5 | -23.2 / -19.2 |

（每格是 杂音 / 40 Hz 以下的冲击，越低越好。）之前切到 CLEAN 时喇叭端有满功率（60 V）的冲击：音色堆栈里还存着 RED 约 190 Vpp 的信号，CLEAN 的 25 倍电平修正把它放大；V1A / V1B 又按名义 305.7 V 而不是下垂后的电压重新起动，在音色堆栈前产生几伏的直流台阶。
RED → BLUE 和理想还差几 dB：理想里 BLUE 一直按自己的状态运行，真机做不到，它只有一组电容，从 LEAD 的工作点过渡到 crunch 的（R20 接上、R18 短路）本身就是一个过程，模型现在做的正是这个。
从静态点起动新通道（不接过状态）时，切到高增益通道要先建立偏置，RED → BLUE 只有 -19.6 / -20.1；把一直运行所有通道换成理想效果要多约 23% 的 CPU，没有采用。

**淡化中途切到第三个通道（v0.5.4 之后）**：之前交叉淡化只有两个位置，第三个通道在淡化中途进来时，两个正在运行的通道里较小的那个被直接切掉（权重最多 0.5 一下变成 0），另一个的权重也跳变。现在每个通道有自己的权重（总和为 1）：每次切换都从当时的权重出发，用升余弦淡到新通道，所以权重任何时候都不跳变；权重大于 0 的通道一直运行到淡出结束，从静音进来的通道接过当时最响的通道的状态。`amp_path_test switch`，A → B，8 ms 后（20 ms 淡化的中途）→ C，杂音 dB（之前 / 现在 / 理想：三个一直运行的前级按同样的权重混合）：

## 过采样和 CPU

v0.4 起非线性部分（Drive、前级、功放）的内部采样率至少 352.8 kHz：44.1 / 48 kHz 工程用 8 倍，88.2 / 96 kHz 用 4 倍，176.4 / 192 kHz 用 2 倍（JUCE 半带 IIR，48 kHz 下延迟 5 个样本）。
`tests/amp_path_test`：重度削波的 1–5 kHz 正弦，非谐波杂音（混叠）4 倍 -50…-55 dB，8 倍 -61…-70 dB，16 倍 -72…-83 dB；8 倍的 CPU 约为 4 倍的 1.7 倍。
做硬件时可以按算力回到 4 倍。

**梯形法会不会在奈奎斯特附近振铃**：梯形法 A 稳定但不是 L 稳定，比一个采样快得多的极点（例如 V3A 的 1k 栅极电阻进 Miller 电容，τ ≈ 0.1 µs，T = 2.8 µs）会映射到 z ≈ -0.87，即一个衰减很慢、在 fs/2 交替的模态。实测（RED 整条链，平滑的类吉他输入，352.8 kHz 和 705.6 kHz 各渲染一次，比较同样绝对频率的功率密度）：352.8 kHz 下各节点（前级输出、V5A 屏极、V3A / V4B / 6L6 栅极、喇叭）在 170–176 kHz 的密度都比 140–160 kHz 低 8–50 dB，没有奈奎斯特处的峰；20–40 kHz 两种采样率相差 0.1 dB 以内。所以不需要换积分方法（例如 BDF2 或混合 TR-BDF2）。

Intel Core Ultra 9 275HX 单核，48 kHz 工程：

| | v0.3.0（4 倍） | 优化后（4 倍） | 现在（8 倍） |
|---|---|---|---|
| Drive + RED 前级 + 功放（`dsp_test` / 基准） | 44% | 24–25.5% | 41% |
| 插件里完整的箱头路径，RED Gain 5 Master 3（`amp_path_test`，含过采样滤波器） | | | v0.4 32%；现在 55%（旋钮在动时 61%：整个前级联立、电源链、V3A 进功放电路；矩阵乘法 4 行一组之前 61% / 66%） |

音色回归测试 `tone_regress.exe`：74 个场景和高精度参考解（容差收紧 1000 倍、原始 Koren 公式）相差 -96 dB 以下，1/3 倍频程频带电平差 < 0.001 dB。
