# 5150 功放元件级模型

代码：`Source/dsp/PowerAmp5150.h`（电路）+ `Source/dsp/DKCircuit.h`（求解器）
LTspice 参考：`spice/5150_power_amp.cir`、`spice/5150_power_amp_drive.cir`、`spice/6L6GC.inc`

## 电路（原理图第 3–4 页）

```
Master → V3A 恢复级 (R5 68k, R14 3.3k ‖ C61 4.7n)
       → C49 22n → 长尾对倒相 V4A/V4B (R46 82k / R58 100k, R52 470, R51 10k, R57 4.7k, R48/R50/R53)
       → C28/C29 47n, R54/R55 220k 偏置, 2.2k 栅极阻尼
       → 2 × 2 × 6L6GC 推挽 (CR200/CR201 回扫二极管)
       → 输出变压器 (Raa ≈ 2.1k, 8 Ω, 磁化电感 30 H, 初级分布电容 2.5 nF)
       → 4×12 喇叭阻抗 (Re 6 Ω, 音圈电感, ~100 Hz 箱体谐振)

负反馈: 喇叭 → R56 39k → (C12 6.8n ‖ VR8 Resonance 1M) → 尾部节点 L
Presence: L → VR9 10k → C8 0.1µ → 地;   V4A 栅极经 C31 47n 以 L 为交流参考
电源: B+ 储能电容带下垂 (sag), 帘栅经 R210 400 Ω 供电
```

## 求解方法

功放里有一个从喇叭回到倒相级的负反馈环。如果按级拆开、用"上一个采样"的值传递，环路里就多了一个采样的延迟，环路增益约 3 倍时会直接振荡发散。所以整个功放（倒相级 + 功率管 + 变压器 + 喇叭 + 负反馈）用 **DK 方法**联立求解：

- 所有线性元件（R、C、L、变压器、电源）合成一个 MNA 矩阵，电位器变化时才重新求逆
- 每个采样只对 8 个非线性端口（2 支 12AX7 + 2 对 6L6 的屏极 / 栅极）做牛顿迭代
- 预测器（线性外推）+ 残差判断收敛 + 失败时从上一个解重新迭代；预测器在噪声输入时会自动关闭

## Master 旋钮

v0.4 起 Master（以及前级 Gain）按真实 6505 的 NAM 捕获校准，刻度和真机一致，见 [nam_calibration.md](nam_calibration.md)。真机在 Post 3 时功放只是轻度饱和，送进功放的电平比"10% 对数电位器"的假设低约 21 dB。

v0.3 用的是 60 dB 对数曲线（"Master 1 干净、2 开始压缩、3 饱和"），比真机推得狠得多，这是当时削波偏硬、高频偏亮的主要原因。旧工程和旧预设读取时会按相同的电位器分压比换算，声音不变。

## 求解器收敛

v0.3.0 给栅极端口的 Newton 步长限制是 4 V。RED 通道前级的陡峭边沿经 C28/C29 会让 6L6 栅极在一个样本内摆动 100 V 以上，46 次迭代也走不到解；不收敛的样本输出错误值，喇叭端出现最高约 300 V 的尖峰（Master 高时可闻的爆音）。现在栅极和屏极共用 40 V 限制：栅流和续流二极管都是 softplus 拐点（拐点以上是线性的），越过去的一步下一次迭代就会自己修正，测试中 0 次不收敛。
