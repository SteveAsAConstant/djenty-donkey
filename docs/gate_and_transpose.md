# 3 段噪声门与 Transpose

## 3 段智能噪声门（`Source/dsp/MultibandGate.h`）

- **检测**：用干净的吉他输入（Input 旋钮之后、箱头之前）判断"有没有在弹"。这里信号最干净，不会被失真后的底噪误触发。
- **动作**：施加在箱头输出上（箱体 IR 之前），也就是噪音真正被听到的位置。
- **分频**：Linkwitz-Riley 4 阶，分频点 300 Hz / 3 kHz，三段相加后频响是平的（测试误差 < 0.001 dB）。
- **每段不同的行为**：

| 频段 | 关闭阈值 | 释放时间 | 默认深度 |
|---|---|---|---|
| 低 (<300 Hz) | Thresh | Release × 2 | 30 %（-24 dB） |
| 中 | Thresh + 3 dB | Release × 1 | 60 %（-48 dB） |
| 高 (>3 kHz) | Thresh + 8 dB | Release × 0.4 | 100 %（-80 dB） |

一个音衰减时，高频先关（去嘶声），低频最后关、而且关得浅（保留延音的"身体"）。
测试（音符以 -30 dB/s 衰减）：高频 1.51 s 关闭 → 中频 1.71 s → 低频 1.87 s。

HQ 移调模式下，检测信号会延迟和移调相同的时间，避免门提前关掉音尾。

## Transpose（`Source/dsp/PitchShifter.h`）

### LIVE 模式：波形对齐的 WSOLA
- 延迟线 + 读取头，读取头的延迟在 20 ms 范围内漂移，到头时换一个新的读取头，用 8 ms 交叉淡化
- 新读取头的位置用**归一化互相关**在 16 ms 范围内搜索，选和当前波形最对齐的位置，所以拼接处没有颤动
- 输入静音时，读取头停在最短延迟处，所以拨弦的起音只有约 **6 ms** 延迟，平均约 15 ms
- 不分频段：时域移调分频段时，各频段拼接时刻不同，相对延迟会漂移几毫秒，分频点附近会出现相位抖动

### HQ 模式：相位声码器时间拉伸 + 重采样
- FFT 2048 点（48 kHz），分析步长 256，合成步长 = 256 × 移调比例，再按同一比例重采样回原时长
- 音高由步长之比精确决定（量化误差 < 2 音分）
- 恒等相位锁定（Laroche–Dolson）：谱峰周围的频点锁定到谱峰相位，和弦不"发虚"
- 起音检测（谱通量）时重置相位，拨弦的瞬态保持清楚
- 固定延迟约 43 ms，会自动报告给 DAW 做延迟补偿
