# C++ 元件级模型 vs LTspice

运行方式：
- LTspice：`LTspice.exe -b spice/5150_lead_preamp.cir`、`spice/5150_tonestack.cir`
- C++：`%USERPROFILE%\vab-build\Release\dsp_test.exe`

条件：B+ 取出厂电源链的怠速值（`Supply5150`：V1+ 305.7 V 供 V1A / V1B / V2A，V2+ 322.1 V 供 V2B / V5B / V5A），V5A 带音色堆栈输入负载（R89 470k → R24 33k ‖ C59 10n + R94 47k），Lead Gain 电位器 0.5，1kHz 正弦，12AX7 用 Koren 模型（两边参数相同）

## 1. 音色堆栈：完全一致

出厂原理图的网络（含输入网络，见 [5150_schematic_notes.md](5150_schematic_notes.md) 第 5 节），由 V5A 屏极（R89 470k + V5A 带 R88 反馈时约 7.4k 的输出阻抗）驱动，负载 VR7 ‖ VR6 = 500k。
32 个测试点（4 组旋钮设置 × 8 个频率）全部吻合，误差 < 0.01 dB。R89 对 R24 的分压让整体电平约 -30 dB，这正是真机 Post 电位器之前的电平。

## 2. 前级偏置与偏置漂移

RED 前级（V1A…V5A）现在整体联立求解（`LeadPreamp5150`，见 3a 节），读的是真实的屏极 / 阴极电压。

|---|---|---|

## 3. 已知差异

- V5A 的负载：R89 → R24 33k ‖ C59 + R94 这一路（`LeadPreamp5150::v5aLoad`）现在默认打开，和出厂原理图一致。和 NAM 捕获比，开始削波段的 H2 多约 1.6 dB；这一段和管子个体有关，NAM 判断不了，所以按原理图保留（见 nam_calibration.md）。音色堆栈本身的输入阻抗没有算进这个负载（只占几 %）
- BLUE 通道只有 V2B–V5A 联立（`LateStages5150`），V1A、V1B、V2A 仍逐级求解：Rhythm 的继电器拓扑在图上还没确认，也没有 Rhythm 的捕获
- 小信号下 V1A / V1B 的谐波，C++ 测得的下限约 -65 dB（re 很小的屏极信号），LTspice 是 -90 dB：这是测量方法（对几百伏直流上的毫伏信号做 DFT）的下限，不是求解误差 —— 否则它会被后级放大，而 V5A 在这些电平上和 LTspice 一致

## 3a. 谐波：逐级求解 vs 联立求解

网表 `spice/5150_lead_harmonics.cir`：完整耦合的 V1A…V5A，12AX7 用 `spice/12AX7_cpp.inc`，和 C++ 的器件方程完全相同（Koren 屏流、Cgk/Cgp、同一条栅流曲线），所以差别只来自电路的解法。110 Hz，Lead Gain 分压比 0.0132，`.four` 取 0.5–0.7 s；`rload` 参数选 V5A 有无 R89 负载。

v0.4 的 C++ 把每一级单独求解：后一级由前一级的开路屏压经戴维南电阻驱动，前一级感觉不到后一级的负载（R32 / R87 上的栅流、R88 反馈网络）。V5A 屏极的 H2（dB re 基波，无 R89 负载）：

| 输入 | LTspice 耦合 | C++ 逐级（v0.4） | C++ 联立 |
|---|---|---|---|
| 1 mV | -56.9 | -57.9 | -57.7 |
| 16 mV | -42.0 | -25.0 | -38.4 |
| 32 mV | -29.4 | -18.6 | -29.6 |
| 63 mV | -32.2 | -24.2 | -32.2 |
| 125 mV | -29.8 | -26.9 | -29.7 |
| 1 V | -16.9 | -16.7 | -16.9 |

逐级求解在开始削波段多出 8–17 dB 的 H2，这正是和真机比较时偶次谐波偏多的主要来源（[nam_calibration.md](nam_calibration.md)）。16 mV 处正好是 H2 的一个凹陷点，对微小差别最敏感；加上 R89 负载时那一点也吻合（-43.2 / -43.5）。

联立求解（`LeadPreamp5150`，6 个三极管 12 个端口，从输入插孔到 C58）和 LTspice 在 6 个屏极上逐点比较，63 mV 输入为例（H1 Vpk / H2 / H3）：

| | V1A | V1B | V2A | V2B | V5B | V5A |
|---|---|---|---|---|---|---|
| LTspice | 3.15 / -54.7 | 2.27 | 2.67 / -34.8 / -41.5 | 118.80 / -34.1 / -22.1 | 154.30 / -45.6 / -10.8 | 130.20 / -32.2 / -10.4 |
| C++ | 3.15 / -56.4 | 2.27 | 2.67 / -35.0 / -41.2 | 118.75 / -34.1 / -22.1 | 154.27 / -45.2 / -10.8 | 130.22 / -32.2 / -10.4 |

所有电平上幅度差 0.1–0.5%，谐波约 0.5 dB（扣除上节说的测量下限）。

求解器（`TriodeNetwork<N>`，`LateStages5150` 和 `LeadPreamp5150` 共用）：所有线性元件和 N 支三极管放进一个 DK 电路，2N 个非线性端口联立 Newton，预测器、步长限制和异常处理同功放；电容从直流工作点开始，没有上电冲击。前两轮 Newton（6 + 40 次）不收敛时，再做最多 200 次带回退（残差变大就步长减半）的迭代：1 kV 尖峰会让栅极大幅正偏，屏流在 Vpk > 0 时极大、Vpk < 0 时为 0 且斜率为 0，普通 Newton 会在 Vpk = 0 两侧来回跳。正常信号从不走到这一步。和高精度参考解（`tone_regress`）相比 RED 前级误差 -85…-121 dB，测试中 0 次不收敛。

## 4. CPU（48kHz 工程，Intel Core Ultra 9 275HX 单核）

`dsp_test.exe cpu`（4 倍过采样），只算前级：

| 通道 | v0.3.0 | v0.4 | 现在 |
|---|---|---|---|
| CLEAN | 6.0% | 2.8% | 2.8% |
| BLUE | 15.9% | 7.7% | 9.9%（V2B–V5A 联立） |
| RED | 16.3% | 8.8% | 25.7%（整个前级联立，12×12 Newton） |

插件里完整的 8 倍过采样箱头路径（`amp_path_test`，RED Gain 5 Master 3，64 样本 block）：旋钮不动平均约 61%，Gain + Presence 一直在动约 66%（v0.4 约 37–40%；V3A 进功放电路之前 54% / 58%）。为了不在精度上让步，省下的只有不影响结果的部分：每支管子的阴极 / 屏极电压只在测试时计算（`Preamp5150 (true)`），旋钮平滑时 Gain / Presence / Resonance（要重建 DK 矩阵）每 128 个样本更新一次、其他每 32 个。
64 样本 buffer 下最坏单个 block 约 94–151%（测量间波动很大）：小 buffer 下偶尔可能爆音，用 128 或 256 样本 buffer 更稳。

做过的优化：Koren 公式里 softplus^1.4 改成三次 Hermite 查表（相对误差 1e-8，`dsp_test.exe tables`）；Newton 总做最后一步修正、步长很小时直接接受（大多数样本只求一次电子管）；线性网络改成状态空间形式。
