## 信号通路

**输入**：输入端 → 桥 T 衰减器（前面板 INPUT：R1A/R1B 600 Ω 双联电位器，R2、R3 620 Ω）→ T1 初级 → T1 次级跨 R4 270 Ω（折算到初级约 675 Ω，就是 600 Ω 端接）→ **R5 27k** → 节点 D；次级另一端接地。

**增益衰减 + 前级（"SIGNAL PREAMP"）**：
- **Q1**（UREI 13-0027，挑选过的 N 沟道 JFET，"VVR"）：漏极 = D，源极 → R10 10k → 地，源极 → **C28 50 µF** → 节点 M（R18/R84 之间）。
- D → C1 1 µF → R8 1k → **Q2**（2N3391A）基极；C2 27 pF 从 Q2 基极到地；R9 560k 从 N3 到 Q2 基极（直流偏置）。
- Q2：集电极 → R13 1M → P；发射极 E → R18 180 → M → R84 180 → 地；E → R85 150 → R86（0–100 Ω，PCB 微调）→ F。
- **Q3**（2N3391A）：基极接 Q2 集电极，集电极 → R14 22k → P，发射极 → R11 82 → N3 → R12 910 ‖ C5 80 µF → 地。
- **Q14**（2N3391A，射极跟随）：基极接 Q3 集电极，集电极接 +30 V，发射极 = 前级输出 O → **R15 6.8k** → F。
- 本地电源 P：+30 V → R17 6.8k，C4 80 µF。
- 闭环增益约 (6.8k + 150 + R86 + 360) / 360 ≈ ×20（26 dB）。
- **LN 电路**：场效应管源极经 C28 交流接到 M（E 电压的一半），栅极：G → R7 2.2M ‖ C6 200 pF → **CTRL**，G → R6 2.2M ‖ C3 200 pF → H → **C9 0.22 µF** → F。音频上栅极 = (CTRL + F) / 2：管子两端电压的一半加到栅极上，抵消场效应管的二次失真；R86 调这个比例（模型里 35 Ω 时失真最小）。
- **CTRL** → **C22 0.22 µF** → 地（启动 / 释放定时电容）。
- O → **C7 1 µF** → O2：前面板 OUTPUT 电位器 **R23 250k**（扫描件写 "250K, 2W"，UA 复刻是 10k），以及比率开关 A 组（侧链输入）。

**线路放大器（"SIGNAL LINE AMP"，Rev D 为甲类）**：
- R23 滑臂 → C8 0.15 µF → **Q4**（2N3391A）基极：R24 2.7M（集电极 → 基极）、R25 2.7M（基极 → 地），集电极 R26 68k → L，发射极 E4 → R27 1.5k → 地。
- Q4 集电极 → C10 1 µF → **Q5**（2N3707）基极。Q5 基极：R29 1.2M ‖ C11 10 pF → Q6 集电极（直流偏置兼高频补偿），R30 150k ‖ R30*（T+C）→ CR1（1N914）→ E4。
- Q5：集电极接 L，发射极 → **Q6**（2N3053，图上标 "2N5055"）基极。
- **Q6**：集电极 → T2 初级 BRN，初级 BLK → +30 V；发射极 → T2 发射极绕组 WHT/BLK → WHT/RED → R32 39 Ω → 地；C14 0.033 µF（Q6 发射极到地）。
- 本地电源 L：+30 V → R34 8.2k，C12 5 µF。
- 反馈：E4 → **R28 22k** → SLT（反馈绕组 SLT–VIO，VIO 接地）——整体负反馈，闭环约 ×15.7（24 dB）；E4 → R31 70k → C13 270 pF → WHT/RED（高频）。
- T2 次级 BLU–YEL + ORE–RED 串联（YEL–ORE 短接），RED 接 SLT；输出取 BLU–RED（浮地）。R33 560 + C15 0.0047 µF 从 Q6 集电极到 RED/SLT。
- 绕组同名端（只有这样是负反馈）：BLK、VIO、WHT/BLK、BLU。

## 侧链（"G.R. CONTROL AMP"）

**比率开关 A 组（侧链输入量）**：O2 → R78 56k → TA → R19 68k → T12 → R20 56k → T8 → R21 56k → T4 → R22 47k → **地**，是一条接地的分压器；按下的按钮把对应抽头（20:1 = TA，12:1 = T12，8:1 = T8，4:1 = T4）接到公共母线 → S9 → C17 → Q7 基极。空载分压比 0.80 / 0.56 / 0.36 / 0.17。TA 到母线另有一个 T+C 电阻（跨在 S4A 上；Rev E 在这里加了 10 MΩ 防切换爆音，模型取 10 MΩ）。

**S9（G.R. 关，装在 ATTACK 电位器上，逆时针到底）**：转换开关，平时母线 → C17，关时 C17 输入接地。

**放大**：
- **Q7**（2N3707）：基极 ← C17 1 µF；R36 1M（集电极 → 基极），R37 470k（基极 → 地），集电极 R38 47k → RB，发射极 → R39 4.7k → N41；RB = +30 V → R51 4.7k，C18 50 µF。
- **Q8**（2N3707，射极跟随）：基极接 Q7 集电极，集电极 +30 V，发射极 → R40 2.4k → N41 → R41 270 → 地。
- **Q9**（2N3707，倒相）：基极 ← R42 180k ← Q8 发射极，基极 → R43 47k ‖ R45 390k ‖（T+C，模型省略）→ 地；发射极 → R48 8.2k → N50；集电极 → R47 47k → +30 V。
- **Q10**（2N3707，射极跟随）：基极接 Q9 集电极，集电极 +30 V，发射极 → R49 2.4k → N50 → R50 180 → 地。
- **R46 47k**：Q10 发射极 → Q7 发射极（整体反馈）。
- 图注：Q7–Q10 挑选 hFE ≥ 250。

**全波整流**：Q10 发射极 → C19 6.8 µF → **CR2**（FD333）→ K；Q8 发射极 → C20 6.8 µF → **CR3**（FD333）→ K（两路反相）。两个阳极各经 R52 / R53 47k 接到 M2，M2 → C21 80 µF → 地（负极性）。

**门限（比率开关 B 组）**：B2 → R58 150 → S0 → R61 470 → S1 → R62 560 → S2 → R63 1.5k → S3（VIO）→ R64 1.5k → −10 V；按钮把 S0 / S1 / S2 / S3（4 / 8 / 12 / 20:1）接到 M2。比率越高，侧链信号越大、门限偏置也越负：高比率的门限更高，和原厂测试数据的顺序一致。全按下时 R61–R63 被短路，串电流变大、B2 被拉低——"全按"模式的偏置偏移就是这么来的。

**"Q" 偏置**：−10 V → R35 10k → QA；QA → R60 3.9k → 地；R59 2k（PCB 微调）跨在 QA 和 R83（T+C，取 0）→ 地之间，滑臂 = B2（场效应管栅极的静态电压）。

**启动**：K → R54 470 ‖ C27 0.022 µF → R55 滑臂；R55 25k 的逆时针端接 K、顺时针端接 CTRL。顺时针到底（最快）时 K → CTRL = 25k ‖ 470 ≈ 461 Ω 加 C27 加速；逆时针时 = 25k。

**释放**：CTRL → R56 5M（顺时针端）→ 滑臂 → R57 270k → B2，R56 的另一段并在 R57 上。顺时针到底 = 5M ‖ 270k = 256k（τ = 56 ms），逆时针 = 5M（τ = 1.1 s）。

## 电源

+30 V（图上标 50 mA）和 −10 V，稳压，模型里当理想电源。

## 没有建模的部分

- G.R. 表头驱动（Q11 场效应管 + Q12 / Q13 差分）：只驱动表头。插件的 GR 表直接从控制电压算（同一个场效应管方程）。
- 立体声联动接口。
- 变压器铁芯饱和（只有线性励磁电感）、漏感、晶体管的扩散电容；1176 自身的噪声。
